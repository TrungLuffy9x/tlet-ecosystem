# Tlét Ecosystem - Siêu Landing Page

Trang Siêu Landing Page chính thức cho Hệ sinh thái **Tlét Ecosystem** (bao gồm **TlétTruyện** và **Tlétfít**).

## 🚀 Công nghệ sử dụng

- **React 18 / 19** & **TypeScript**
- **Vite** siêu tốc
- **Tailwind CSS v4** với Custom Ambient Glow design system
- **Lucide Icons**
- **Cloudflare Pages** deployment ready

## 🛠️ Hướng dẫn phát triển

```bash
# Cài đặt dependencies
pnpm install

# Khởi chạy môi trường Dev
pnpm dev

# Build sản phẩm
pnpm build
```
